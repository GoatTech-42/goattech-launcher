# GoatTech summit mark

Original vector source from the v2 Summit A direction Luke chose on November 7, 2026.
The two SVG files are unchanged from the reviewed design package. The enclosed counter
is used from 48 logical pixels; below that, the counter-free mark keeps the silhouette clear.
The launcher renders these as tinted SVG masks so both light and dark themes work.

The splash wordmark uses the already-bundled Bricolage Grotesque Display Bold face.
It uses the same glyph outlines for every letter, including H. No extra font is downloaded.
The earlier design mock used a heavier weight and wider tracking; this source keeps the
existing splash text size, weight and per-letter animation.

These assets are launcher branding. They do not replace Horizon's game or instance icon.
