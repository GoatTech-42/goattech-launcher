# Opening wordmark font

GoatTechOpening-Bold.ttf is an intro-only subset of the bundled Pixelify Sans Bold.
It keeps the wordmark's advances, vertical metrics and other glyphs unchanged.
The H has a straight crossbar instead of Pixelify's raised middle notch, so it no
longer looks like an M. The animation, size and spacing are unchanged.

Regenerate from the repository root with `python3 tools/bake_opening_font.py`.
Run `python3 tools/test_opening_font.py` to check the outline and layout metrics.
Both commands use fontTools. The application does not need Python or fontTools.
